# 1.0.17 完整载荷发布

线上基线：1.0.16；目标：1.0.17。

本版本合入 PR #191、#189、#188、#187、#108：支持管理员在当前群通过自然语言按群切换插件并同步软件开关，补充管理器皮肤、短剧资源和 iPhone 投屏修复，并加入付费迁移额度累计与扣减。改动包含运行时 Python、AstrBot/插件补丁、管理器和内置 Web UI，按规则发布完整载荷。

## 兼容性与交付范围

- 完整载荷包含管理器、运行时、插件资源、AstrBot 适配补丁和更新清单；保留现有用户配置、授权数据和账号数据。
- 发布候选须以已合入 `master` 且 quality CI 通过的提交生成，并完成签名、资产大小与 SHA-256、公网完整下载和稳定清单回读校验。
- 真实微信、干净 Windows、安全软件和安装升级回滚验收未执行，不能由 CI 或下载自检替代；这些项目保留为待用户验收。

## 发布验证

- PR #191、#189、#188、#187、#108 已合入 `master`，对应 quality 检查通过。
- 正式发布时执行冻结管理器自测、完整 payload 校验、GitHub Release 资产公网 HEAD/GET/SHA-256 校验、稳定清单切换、回滚目标记录和下载冒烟。
