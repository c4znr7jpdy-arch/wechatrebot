# 1.0.27 模型服务、长期记忆与管理器优化

## 更新内容

- 保存模型后保留当前编辑页。模型卡片完整显示长名称，可单独测试，也可批量测试配置中的模型。测试耗时或失败状态会保留到模型配置变更。
- 可以设置长期记忆的默认向量模型，服务故障时自动尝试其他已配置的向量模型。首次切换需要重建文档和图谱索引，耗时及请求量随记忆数据量增加。索引重建期间仍可进行关键词检索，旧索引和原始记忆会保留。
- 减少启动、插件中心、群头像和联系人查询的重复请求。管理器配置写入复用同一把进程内锁。群策略只在相应页面和有效会话中轮询。
- 管理器和插件中心共享字体资源。构建与增量预检共用 AstrBot 核心补丁的顺序和指纹定义。

本次包含 [PR #225](https://github.com/c4znr7jpdy-arch/wechatrebot/pull/225)、[PR #226](https://github.com/c4znr7jpdy-arch/wechatrebot/pull/226) 和 [PR #227](https://github.com/c4znr7jpdy-arch/wechatrebot/pull/227)。
