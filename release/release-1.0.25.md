# 1.0.25 自动更新优化

## 范围与来源

线上基线为 1.0.24，本次仅发布管理器增量。PR #221 已合入 `master`（`e9e9c2e`），增加完整载荷自动覆盖窗口、交接协议、后台暂存直接移动及单一回滚事务；不重建或分发 Python、AstrBot 核心补丁、HOOK、插件或 FFmpeg。

用户已明确授权“合并 发布线上”。沿用当前会话已确认的直接发布要求，不追加分发授权或安全审查；没有执行的验收不标记为通过。

## 客户可见变化

- 完整更新准备好后只需确认一次，独立窗口自动覆盖原目录、打开新版，成功后清理并退出，无需下一步或完成。
- 减少旧文件重复复制及新文件二次暂存，保留客户配置；失败时显示恢复结果。
- 修复取消与旧进程退出的交接边界，防止同时启动重复更新任务。

1.0.24 首次升级仍按原有交接流程执行；安装本版后发起后续完整更新，才启用新窗口和直接移动暂存文件。首次安装继续使用 1.0.24 完整安装包，GitHub Latest 保留该完整安装版。

PR #221 提交 `37036fe` 的完整 CI 已通过：manager 6110 passed、2 skipped，player 110 passed，冻结管理器构建自检及汇总均成功。版本准备提交另行运行元数据校验和 CI。
