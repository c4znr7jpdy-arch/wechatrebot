# 1.0.19 管理器增量发布

线上基线：1.0.18；目标：1.0.19。发布源来自最新 master，包含 PR #204 的消息中心退群标识与 #202 的页面保留改进。

本次仅构建和发布管理器 EXE 增量，复用现有更新签名、GitHub 资产验证及稳定清单切换流程。运行时、插件和 AstrBot/桥接补丁不会随管理器包更新，不能将 master 上的其他运行时改动视为已部署。

用户明确要求快速发布且无需测试，本次跳过 pytest、额外 CI 等待和远程下载冒烟；构建器要求的冻结产物检查及签名、公网大小/SHA-256、稳定清单读回校验保留。未启动机器人，未执行真实微信、干净 Windows、安全软件及实际升级回滚验收。
