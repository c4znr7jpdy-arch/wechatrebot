# 1.0.15 管理器增量发布

线上基线：1.0.14；目标：1.0.15。

本版本包含更新弹窗多行和 emoji 展示、网页维护更新说明、草稿保存、预览和二次确认发布流程。仅发布管理器增量；授权后台独立部署。

## 兼容性与交付范围

- 1.0.14 及更早客户端本次升级仍显示签名清单中的默认说明；安装 1.0.15 后，后续更新可读取网页维护的说明。说明获取失败时回退默认文案。
- 管理器包只替换管理器 EXE。主干中独立的短剧插件补丁不包含在本次管理器包内。
- 不更改强制更新策略、数据库结构、Python 运行时、依赖锁或 HOOK。无需完整载荷。

## 本次检查适用性

- HOOK 再分发、安全审查、真实微信收发、运行模块/运行时/第三方许可证及客户协议：本次不更改这些组件，沿用已发布基线；不把历史 pending 认定为已通过。
- 管理器：执行冻结自检、清单签名验证、产物摘要及公网下载校验，证据保存在候选产物目录。Authenticode 按本次实际状态记录。
- 客户文档与敏感文件：候选只含管理器 EXE 和载荷清单，不包含开发者配置、凭据、数据库或日志。
- 本次先用 prepare-only 上传候选，保留 1.0.14 稳定清单及回滚目标；最终由维护者在后台填写说明、预览并二次确认切换。
- 真实微信、干净 Windows、安全软件和安装升级回滚验收未执行，不能由 CI 或下载自检替代。备份、线上验证和回滚目标在部署与候选收据中单独记录。
