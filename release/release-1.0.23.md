# 1.0.23 机器人停止修复候选

线上基线为 1.0.22。本候选包含已合入 master 的 PR #218、#211 和 #217；本版本的核心修复来自 #218（提交 868eec5）。

## 用户可见变化

- 旧账号或旧授权事件不会再阻断当前仍有效账号的回复引擎。
- 真实的换号、授权到期、撤销和连续健康检查失败仍按现有规则阻断服务。
- 授权守卫停止日志记录脱敏原因和时间，便于区分授权停止与普通网络重连。
- HOOK 瞬时连接失败会进行有界重试，减少健康检查误判。
- 发布器支持按已登记基线生成签名组件更新；本候选因包含运行时授权模块修复，仍需完整载荷。

## 更新方式与验证边界

本次涉及运行时 Python 授权模块，组件增量不能覆盖修复，线上交付必须使用完整载荷。完整载荷构建、签名、打包和上传需在本说明确认后执行。

已完成 	ests/test_license_runtime_guard.py 定向测试和元数据/语法轻量检查；不启动机器人，不更新本地安装。真实微信、干净 Windows、安全软件、升级回滚和人工授权验收待维护者验证。管理器 Authenticode 若仍为 NotSigned，发布记录将如实保留该状态。
