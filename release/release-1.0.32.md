# 1.0.32 天气数据恢复与更新速度优化

线上基线为 1.0.31。本次交付完整应用更新及标准 Inno Setup 在线安装器，复用已发布的签名运行环境；依赖锁、Python、FFmpeg 和环境包均无变化，不重建完整环境。

- 天气实时补充、逐小时预报及七日温度曲线遇到短暂网络超时后，采用一次有界重试，并为重试提供更充足的连接和读取时间。正常请求继续使用原快速预算，保留五分钟成功缓存及并发请求；持续不可达仍显示数据暂缺，不生成替代天气。
- 收录已合入的自动更新优化，减少更新过程中的重复文件读取。

复用现有应用构建、源码校验、发布扫描、Ed25519 清单签名、公网资产验证、稳定清单切换和失败恢复流程。候选必须基于已合入 master 且通过 CI 的版本提交；本次天气定向检查已通过 36 项，真实接口首次连接超时注入后恢复了 5 个小时点和 7 天曲线。

发布时保存候选、产物大小与 SHA-256、环境清单、原稳定清单和最终回执；验证标准在线安装器、隔离安装及 1.0.31 升级/失败回滚，检查用户配置与模拟数据保留。新产物和复用的历史环境资产通过公网 HEAD、完整下载与摘要校验后才切换 stable；稳定清单验签和下载冒烟成功后提升 Latest。回滚目标为 1.0.31，历史环境资产保留。证据归档于本次工作区 artifacts/r32 和 artifacts/release-prep。

沿用已授权的 NotSigned Windows 产物交付策略，更新及环境清单继续验签。本次未更换 HOOK、增加依赖或第三方组件；既有许可证、商业授权等人工记录不因代码或 CI 通过而改为已验收。真实微信、干净 Windows 和安全软件兼容性未在本次重新验收。不安装到维护者的正在使用的客户端，不启动机器人。
