微信机器人商业版 - 开始使用
============================

1. 双击同目录的 WeChatReBot.exe。
   请保留同目录的 payload.wrb 和 DISTRIBUTION-MANIFEST.json，不要只复制 EXE。
2. 安装程序已经填写推荐目录，直接点击“下一步”和“安装”即可；也可以点击“浏览”更换目录。
3. 安装完成后默认自动打开机器人管理软件，也可以从桌面或开始菜单重新打开。
4. 软件首次打开会自动检查微信；找不到或版本不支持时，请按页面提示安装或手动选择 Weixin.exe。
5. 机器人名称、人设、回复模型和各项功能都在软件内配置，保存后真实生效。

本发行包不含微信客户端或微信安装程序。请自行从官方渠道安装受支持的微信版本。
安装阶段不会自动启动微信或机器人服务；安装完成后，双击控制台并点击“一键启动”，程序会自动拉起微信，登录账号即可开始运行。

遇到问题时，请在控制中心点击“导出脱敏诊断”，将生成的 JSON 文件发给技术支持。
需要配置功能时，请进入“功能中心”。机器人运行时会通过正式配置接口保存并立即应用，未运行时写入同一正式配置文件并在下次启动生效；密钥默认不回显，留空不会意外覆盖。
控制中心可备份和恢复 config/data。备份包含客户配置与 API Key，请勿上传到公开位置。
控制中心启动后会自动检查签名更新；发现新版本时，点击“立即更新”即可完成下载、校验、安装和重新打开。
