微信机器人商业版 - 开始使用
============================

1. 双击同目录的 WeChatReBot.exe。
2. 第一步选择机器人的安装目录；程序在您确认前不会安装文件。
3. 程序会查找本机现有的 Weixin.exe；找不到时请手动选择。
4. 填写机器人名称、简称和人设，可选头像与模型服务。
5. 安装完成后，从桌面或开始菜单打开“微信机器人控制中心”。

本发行包不含微信客户端或微信安装程序。请自行从官方渠道安装受支持的微信版本。
安装程序不会自动启动微信、AstrBot 或 HOOK；服务只会在您点击“启动机器人”后启动。

遇到问题时，请在控制中心点击“导出脱敏诊断”，将生成的 JSON 文件发给技术支持。
控制中心可备份和恢复 config/data。备份包含客户配置与 API Key，请勿上传到公开位置。
