# 1.0.29 激活与续费体验优化

月卡和年卡使用统一激活码，新用户开通、老用户续费和试用转付费自动识别。续费保留原授权和微信绑定，未到期从原截止接续，已到期从兑换时起算。

增加微信换绑次数码，同一个兑换入口显示余额变化。次数码只增加换绑额度，不改变到期时间或立即切换微信。

管理后台简化为发码、客户授权、发码记录。普通发码无需客户参考号，备注选填；可查原码并从客户详情恢复授权或办理换电脑。换电脑沿用现有设备编号和换机码流程。

修复群聊画像资源清单缺失。由于授权客户端同时复制在管理器和运行时内，本版本的新增码类型及校验需要同步更新授权运行时；现有安装基线的严格校验拒绝仅发布管理器或组件包。交付方式为完整载荷更新及标准在线安装器，完整构建须取得本次单独确认后执行。

授权服务与备份脚本须先升级，数据库结构为 4；服务回退需要匹配的数据库和历史密钥。客户更新的稳定清单回滚目标为 1.0.28。

维护者本次明确要求跳过 CI 等待并发布。激活功能本地定向回归为 309 项通过、1 项平台跳过；发布仍保留签名、产物大小与 SHA-256、下载验证、隔离升级冒烟和回滚清单检查。实际发布结果以回执为准，不将尚未完成的 CI、真实微信、干净 Windows 或安全软件验收记为通过。
