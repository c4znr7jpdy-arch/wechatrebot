# 1.0.13 管理器紧急更新

线上基线：1.0.12；目标：1.0.13，可选管理器增量更新。仅替换管理器，不更新运行时、插件、微信连接组件和原生二进制。

修复：登录确认及首次引导遮罩取消实时背景模糊；遮罩期间暂停后台动画；相同状态轮询复用运行按钮图标和全局状态节点，避免重建；交互锁仅在实际变化时写入。复用既有登录、授权绑定和启动流程。

用户于 2026-11-08 明确要求“改好这个后，马上发布线上，无需测试，我需要速度”。本次按该指示不增加测试、不等待本次 CI；这是本次紧急发布例外。已有未完成的验收条目继续保留 pending，不报告为通过。管理器按既有实际 NotSigned 策略交付；更新清单保留 Ed25519 完整性签名。构建器固有的冻结自检及发布器固有的公网 SHA-256、稳定清单验证和失败回滚保留。

用户同时报告的 13002 已由安装日志定位到微信连接 API 在 30 秒内未监听、注入器仍在运行后桥接退出。尚未证实与界面闪烁为同一原因，本更新不宣称已修复该桥接超时，也未进行真实微信、干净 Windows 或杀软验收。

许可/资源：仅交付管理器，沿用既有运行时与原生组件，本次未增加第三方依赖或插件。回滚目标：v1.0.12 的版本化稳定清单。构建摘要、公网验证及最终源码提交由 artifacts 下 publication-receipt.json 记录；若上传或验证失败，发布器不切换稳定清单或恢复上一清单。
