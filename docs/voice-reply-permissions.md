# 联网回复与插件权限

## 回复规则

实际调用引擎登记的联网搜索或网页提取工具后，该条用户消息的回复保持文字，不进入内置 TTS、语音克隆或表情语音。语音工具与联网工具出现在同一批调用时，整批执行前即设置限制，不依赖工具排列顺序。限制只属于当前消息；下一条没有联网查询的消息仍按原语音设置处理。

语音工具被拒绝时返回明确的文字回复提示，不返回可再次发送的音频路径。通用发送工具也拒绝该消息的语音组件和可识别的音频文件，防止转为文件重发。没有联网查询的显式朗读、自动语音概率和表情触发规则保持独立。

表情语音需要当前聊天同时允许 `jiang_mimo_emoji_voice`、`astrbot_plugin_mimo_tts_clone` 和 `meme_manager`。依赖关系由共享权限模块统一计算；任意依赖未激活、被全局禁用、被会话禁用或未获当前聊天授权时，保留原文字和表情，不请求语音合成。

## 权限检查

群聊和普通私聊均应用账号下的 `bot_enabled` 与 `allowed_features`，再与全局插件集、插件激活状态和会话禁用列表取交集。能力检索与执行复用同一权限实现。群聊的“图来”独立授权保留；私聊沿用界面的“常用指令”整体授权。

合成前与发送前分别检查权限。等待上游合成时关闭权限，已经生成的语音也不会发送。后台语音任务记录来源账号，恢复、处理及逐段发送时复核当前账号和权限；权限拒绝不再额外发送失败通知。旧任务缺少授权记录或账号时不自动补发，以避免升级后误发旧语音。

Twitter、主动聊天、米游社定时签到摘要及 Office 配置目标的调试通知，均通过共享后台发送入口检查接收方权限并绑定账号。主动聊天在调用 TTS 前检查权限，只执行当前允许的装饰钩子。表情图片在转换完成后复核权限；微信消息回复沿用原事件的发送入口，保留原账号与回复信息。权限读取失败或账号无法确认时停止发送，不回退为未检查的发送路径。

这些检查复用已有会话启停、群聊/私聊策略、能力路由、发送接口和补丁组装机制。没有更改插件命令的管理员条件、写操作确认约束、定时任务接收开关、安静时段或业务 API。

统一调度继续拒绝已禁用或已修改的任务，验证原账号、接收方及功能可用状态；桥接层继续验证运行授权、接收开关、安静时段和每日限额。洛克王国的旧定时循环只登记在历史 NoneBot 启动装饰器中，兼容层不执行这些装饰器，当前 AstrBot 初始化只启动渲染缓存清理，因此没有为未运行的旧循环新增发送路径。

## 验证范围与交付

定向离线测试使用实际应用补丁后的代码，覆盖联网工具调用顺序、下一条消息隔离、依赖权限交集、私聊授权、合成中撤权、后台账号变更、旧队列恢复和正常授权路径。测试不启动机器人，也不调用语音或微信服务。

本次执行了语音/共享权限 195 项、后台权限 18 项定向测试，并检查了能力路由、命令授权、工具生命周期、调度策略、补丁组装、运行时指纹和 CI 的 Twitter 回归入口。固定源码校验 `python scripts/source_inputs.py`、`python -m compileall -q src runtime scripts` 和 `git diff --check` 均通过，四个引擎补丁按正式顺序应用后可编译。完整项目测试由 PR CI 执行。

额外执行的 Twitter 插件内部四文件测试有 17 项未通过，涉及初始化夹具缺少字段及既有列表/收集预期；没有将该组报告为通过。本次受影响的媒体发送、微信集成和投递历史 79 项通过。独立 WebChat Live Mode 流式语音不属于本次微信回复改动。

实际微信接收、上游 TTS 延迟与安装后行为仍需运行环境验收。联网回复省去语音合成等待，但本次没有修改上游语音服务的速度、排队或重试策略。

目标版本保持 `0.9.9`。此次包含 AstrBot 核心补丁，安装时需要完整载荷，不能只替换管理器或插件。源码 PR 保持未合并；本次没有构建、安装或发布。
