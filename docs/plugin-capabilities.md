# 插件能力发现与自然语言调用

机器人通过 `jiang_capability_router` 查询当前会话可用的插件、标准命令、插件声明和本轮已提供的专用 AI 工具。目录在查询和执行时重新读取，不维护一份永远不变的插件名称列表。停用、卸载、命令改名及会话授权变更会反映到下一次查询；原生 AI 工具仍受人格工具范围和模型的工具调用能力限制。

## 新增插件怎么办

1. **插件有 `@filter.llm_tool` 或 FunctionTool**：按 AstrBot 的原生方式注册即可。工具启用且进入当前人格/会话的模型请求后，模型能获得参数说明并直接调用；网关不重复封装该工具。
2. **插件有标准 `@filter.command`**：启用后自动进入目录，提供真实命令名称、参数及执行 ID。网关通过 `capability_execute` 调用原处理器，不模拟另一个用户，也不会提升管理员身份。未声明风险的命令默认要求用户发送 `执行 完整命令`，防止把问用法误判成修改操作。
3. **插件使用正则、消息事件或后台任务**：简介自动进入目录。需要精确用法或 AI 代为执行时，在插件 `main.py` 所在目录添加 `capabilities.json`。未声明执行入口的后台功能只说明用途，仍按原配置自动运行。

新增插件本身仍要完成依赖、平台和发布清单适配；“能被发现”不等于任意市场插件都能在微信上正常运行。将插件加入当前会话允许功能并启用后，才会出现在该会话的目录中。

## 能力声明

```json
{
  "schema_version": 1,
  "capabilities": [
    {
      "id": "search",
      "description": "查询公开书目信息并发送到当前聊天",
      "handler": "search_books",
      "message_pattern": "查书 .+",
      "examples": ["查书 三体"],
      "effect": "read"
    },
    {
      "id": "subscription",
      "description": "管理订阅，请使用插件设置页",
      "examples": [],
      "effect": "write"
    }
  ]
}
```

- `id` 是插件内部唯一的标识符；公开 ID 自动加上插件名，避免多个插件互相覆盖。
- `handler` 必须是本插件已经注册的消息处理方法名。省略时仅提供说明；不能填写任意模块、文件路径或私有函数。
- `message_pattern` 对完整消息做正则匹配。执行还必须通过原处理器的过滤器；声明不能绕过原权限。标准命令输入不含唤醒前缀；旧正则若要求 `/`，示例和表达式应明确保留它。
- `effect=read` 仅用于已审查的查询、生成内容及向当前会话回复，不得用于配置修改、跨会话推送、报名、删除或账号操作。缺省按 `write` 处理；写操作只接受当前真实用户消息中的完整执行指令，模型传入的“已确认”不算授权。
- 写操作示例：模型提出 `删除订阅 123` 后，用户发送 `执行 删除订阅 123`。工具重新读取权限与入口，参数和对象必须完全相符。同一条用户消息内同一操作只执行一次。
- 文件须为有效 JSON，schema 版本为 1，最大 64 KiB。格式错误会记录插件名并忽略声明，插件原命令不受影响。
- 描述和示例供模型选择功能，不要包含账号、Token、内部配置值，也不要写覆盖系统规则的提示词。

原插件的消息过滤、管理员权限、会话启停和微信群功能授权仍在执行前检查。网关只执行命中的目标处理器，不运行其他消息监听器。处理器直接发送或返回消息结果时沿用它的消息内容；专用工具仍走 AstrBot 原生工具链。需要独立 `ProviderRequest` 的命令须使用原消息入口，不在网关内部递归启动新的模型会话。缺少结果时不会宣称成功，也不会自动重试可能已发生的操作。

## 当前项目接入

现有天气、新闻、油价、Epic、B站动态等继续复用原能力实现，只有依赖插件当前可用时才展示和执行。活动报名桥接也要求目标插件确实启用并提供执行方法。

画图、影视搜索、资源检索和定时列表已提供声明；视频理解、主动聊天等自动行为有用途说明。声明在 `runtime/capability_declarations/` 维护，通过 `release/source-manifest.json` 复制到对应插件目录。新插件自行携带声明即可，不需要修改网关的功能枚举。

网关的权威源码是 `runtime/jiang_capability_router/`。其源清单已改为当前仓库，旧的命令清理补丁已合入源码并删除，避免构建时重复应用。

## 验证边界

离线测试覆盖动态启停、命令改名、会话权限、声明校验、重复调用拦截及结果状态。实际微信卡片、模型是否正确选择工具和外部服务结果需要安装后验证，离线通过不代表所有插件都已完成真实聊天验收。
