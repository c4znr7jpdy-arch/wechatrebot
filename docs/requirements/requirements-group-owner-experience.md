# 群主管理体验：需求与边界

## 问题

非技术群主希望在电脑里选择自己的群、决定机器人在群里做什么。当前产品以安装模块为中心：把“已装上”当成“有用”，把“无 Schema”当成“不用准备”，让群主在群里发送 `/sid` 获取配置标识，且部分功能名称与实际作用不符。

本次根据用户明确场景和实际源码评估，不把面板字段数量当成易用性，也不假设所有人需要车辆、游戏、运维或自动改代码能力。

## 优先需要

1. 在管理器内辨认和选择机器人账号所在群，手动静默刷新，不产生群消息。
2. 按群名选择配置对象，正确生成各功能需要的标识格式；选择只进入草稿，保存仍走已核验的热更新流程。
3. 每项功能说清楚实际用途、谁会用、还需装什么/绑定什么/付出什么、首次使用步骤和是否会主动发消息。
4. 区分群管理常用、兴趣选配、进阶维护与底层支持；列明重复能力和不建议默认提供的功能。

## 已确认约束与待验证假设

- 已确认：用户角色是群主，但机器人登录账号不一定是群主。不能用用户身份推断机器人管理权限。
- 已确认：旧微信注入实现不在交付范围；仅使用正式新连接已有的群信息读取能力。
- 已确认：不授权启动、停止、重启机器人，不发送测试群消息，不绑定第三方账号，不上传发布包。
- 已确认：车辆提醒所需的安卓通知转发链路不是通用群管理能力，不进入当前客户版交付清单。
- 待核验：群接口提供的成员数、群主、角色和刷新时效。没返回的数据明确显示未知，不能猜测或伪造。
- 待核验：各功能的目标群字段是否用原始群标识或完整会话标识，逐字段核对后才提供选择器。
- 评估建议不等于删除/停用授权：本轮不自动改已有启用状态、账号绑定或用户配置。

## 本轮验收

- 点击“群聊”显示群名、群标识和接口实际提供的信息；可搜索、复制、重新读取。
- 点击“刷新群列表”实际重新调用只读群接口，不以本机历史记录冒充完整群列表，不发送 `/sid` 或其他消息。
- 失败保留同账号的旧列表并标记未更新；账号变化清空旧账号列表；没有缓存与接口空列表分别说明。
- 受支持的群配置字段可直接选群；原值和未列出的值保留，按需追加，不自动保存或开启推送。
- 对当前 24 个运行模块完成有源码依据的必要性/上手成本评估；其中 23 项面向用户显示，隐藏底层模块不参与功能数量统计；明显误名、遗漏的外部前置必须修正。

## 暂不承诺

踢人、禁言、群公告编辑、群权限自动识别、下载安卓 App 或代绑账号；不将群信息刷新说成拉取全部微信历史。对于权限缺失、维护接口或不适宜内容的功能，先记录阻断与取舍建议，再决定重做、移除或单独交付。

## 全量功能必要性与上手成本评估

本表以当前 `release/feature-set.json` 为事实源：完整载荷交付 24 个运行模块，其中 23 项在功能中心可见；新安装默认启用 10 个运行模块，其中 9 项对用户可见。更新不得擅自覆盖现有客户的启用状态；“待适配/待修复”不得以已可用状态销售。

| 功能 | 实际作用与目标用户 | 额外准备 / 群聊影响 | 结论 |
|---|---|---|---|
| 群聊上下文（天使之心） | 调节群聊回复节奏、多人上下文和接话方式 | 需选择允许会话；不是长期记忆库 | 群聊常用，保留并纠正名称 |
| 长期记忆 | 保存对话总结，并在用户明确询问过去内容时优先召回 | 默认跳过普通寒暄的检索；需向用户说明删除、备份和恢复边界 | 默认启用，作为唯一默认主记忆 |
| 情感与关系 | 提供好感度、情绪和精简社交上下文 | 默认不采集原始消息、不自动学习或覆盖人格 | 默认启用，保持轻量上下文模式 |
| 资源检索 | 查询外部资源索引 | 需外部索引；有内容授权与合规风险 | 普通群管理无刚需，新安装不默认启用 |
| 语音克隆 | 用获授权音色把文字转语音 | 需要 MiMo 服务、参考音频和用量成本 | 进阶选配 |
| 外部向量记忆（进阶替代） | 以 Mnemosyne、Milvus 和 Embedding 模型提供向量记忆 | 需要额外服务和运维；启用时替代默认长期记忆，不能并行作为主记忆 | 进阶选配，普通群主默认关闭 |
| 点歌 | 群内点歌与在线音源回退 | 音源可用性和授权受第三方影响 | 低门槛群聊常用 |
| 链接解析 | 解析群内分享的视频、图集和音频链接 | 部分平台要登录信息；建议群内要求点名 | 群聊常用 |
| 群聊兼容 | 兼容微信群成员标识和点名 | 无用户配置，不提供用户操作入口 | 默认启用的底层支持；功能中心完全隐藏，不参与搜索和数量统计 |
| 主动聊天 | 在指定会话和时段主动发消息 | 会真实打扰联系人；需白名单、频率和测试群 | 进阶选配，默认谨慎关闭 |
| 群聊分析 | 生成话题、成员画像、金句和日报 | 读取新桥接成功接收的本机群消息，按当前机器人账号和群聊隔离；安装前或离线期间无法补拉 | 群管理有价值，已解除记录源依赖，按需启用 |
| 自动改代码（Self Iterative） | 读写、加载和卸载功能代码 | 实验性、高权限，错误可能破坏运行功能 | 小白与新安装默认项中移除 |
| 功能调度 | 把自然语言请求路由到对应功能 | 无用户配置，依赖目标功能已就绪 | 默认启用，普通用户通常无需调整 |
| 常用指令 | 新闻、天气、油价、Epic 和趣味查询 | 不同子能力可能分别需要账号或密钥 | 群聊常用 |
| 群成员变动通知 | 提示入群、退群和群昵称变化 | 依赖微信成员事件；不能编辑群公告，当前无按群开关 | 群管理常用，纠正名称并继续补按群范围 |
| 图片生成 | 文生图、图生图和模型管理 | 需要生图服务；Grok 4.6 聊天模型不等于生图模型 | 场景选配 |
| 表情语音 | 把表情回复转为匹配情绪的语音 | 同时依赖语音克隆、表情管理和服务费用 | 进阶选配，依赖未就绪时关闭 |
| 米游社签到 | 米游社账号绑定、查询和签到 | 每位用户需在私聊绑定自己的账号 | 兴趣选配 |
| 复读功能 | 连续相同消息时参与复读 | 无额外配置，但会增加群消息 | 归入基础功能；娱乐群可开启，工作群关闭 |
| 洛克王国助手 | 角色、阵容、交换和家园等游戏能力 | 需要二维码或凭据绑定游戏账号 | 兴趣选配，纠正“运势”误名 |
| 定时任务 | 创建和管理推送、签到计划 | 写操作按当前会话隔离；仅可靠管理员可改，微信无法确认群角色时拒绝；共享账号签到仅限机器人管理员 | 群管理有必要，权限边界已修复，仍按需启用 |
| 短剧 | 搜索内容并安排群推送 | 依赖内容源、授权和播放器 | 内容分享群选配 |
| 视频理解 | 为微信短视频抽帧、提取音轨并总结 | 需要视觉模型；音频能力不可用时只能退化 | 短视频较多的群建议保留 |
| 表情管理 | 管理表情包、会话绑定和可选云同步 | 本地可用；云同步才需要图床或存储账号 | 群聊常用 |

### 新安装分层建议

- 默认日常层：群聊上下文、长期记忆、情感与关系、点歌、链接解析、功能调度、常用指令、视频理解、表情管理，共 9 项用户可见功能。
- 隐藏底层层：群聊兼容默认启用但完全隐藏，与上述 9 项合计为 10 个默认启用的运行模块。
- 基础按需层：群成员变动通知、复读功能、群聊分析、定时任务和短剧；用户按群用途决定是否开启。
- 进阶与兴趣层：资源检索、语音克隆、外部向量记忆、主动聊天、自动改代码、图片生成、表情语音、米游社签到和洛克王国助手。
- 已解除阻断：群聊分析已改读账号与群聊双重隔离的桥接消息库；定时任务已补当前会话与可靠管理员权限校验。
- 不建议默认：资源检索、外部向量记忆、自动改代码和主动聊天。
