# 商业版桌面控制台需求

## 已确认目标

客户完成安装后，双击唯一入口进入自有品牌控制台。运行中心提供“一键启动”：先检查环境和配置，再启动回复引擎，随后自动拉起客户已安装的微信；客户只需在微信窗口完成登录，控制台自动识别并显示在线。

## 2026-09-03 实现与验收矩阵

| 需求 | 当前实现 | 可验证结果 |
| --- | --- | --- |
| 傻瓜式安装 | 两步向导；推荐目录已自动填写，用户可直接“下一步 → 安装”，也可浏览更改；完成后默认打开管理软件 | 安装目录经过固定磁盘、可写、剩余空间、非系统目录和路径长度校验；数据封装为单个 `payload.wrb`，解压写入时同步计算哈希 |
| 不捆绑微信 | 安装载荷和发布扫描明确拒绝微信客户端、微信安装包及旧 Hook 文件 | 首次及每次打开软件都重新检查本机 `Weixin.exe`、x64 架构和受支持版本 |
| 一键启停 | UI 只调用生命周期控制器；启动顺序为回复核心就绪后再连接微信；只有连接、身份和心跳同时正常才显示“机器人可用” | 停止时至少连续两次确认微信进程、连接、心跳与身份均已消失，才关闭后台服务 |
| 进程恢复 | 管理器关闭再打开时，根据可执行文件路径、进程创建时间和就绪端口重新接管既有服务 | 防止 PID 被复用后误认或误关其他程序 |
| 功能真实配置 | 功能中心读取每个交付功能的 `_conf_schema.json`；运行中通过本机引擎配置 API 保存并热重载，离线时原子写入同一正式配置文件 | 布尔、数字、选项、多选、模型选择和密钥字段均有真实控件；密钥不回显，空白保留，显式操作才清除 |
| 高级功能页 | 短剧定时推荐、签到管理等功能显示“高级配置”，打开白标高级页 | 管理界面不暴露底层框架首页或原始插件管理入口 |
| 定时任务 | 全局页读取各功能现有任务，支持暂停、开启、修改和删除；功能自己的高级页继续保留 | 不复制或破坏原功能任务存储逻辑 |
| 聊天记录 | 产品自有数据库增量读取长期记忆数据，支持个人/群聊、搜索、日期筛选和导出 | 群名称、群昵称、发送人微信名、wxid、内容和时间从新连接层一直保存到管理页 |
| 远程更新 | 已实现签名清单检查、下载、哈希与逐文件校验、事务安装和失败回滚 | 正式启用仍需配置发行地址与私钥，并完成签名发行演练 |

### 本期实际交付功能

1. 聊天记录与长期记忆：Schema 配置，另有数据页；第三方许可证待正式放行。
2. 音乐点播：Schema 配置；默认星之阁，失败时使用网易云直连源，不依赖本地 Node/PHP 服务。
3. 短剧解析：Schema 配置与定时推荐高级页；中间页地址和令牌可配置。
4. 常用指令：内容服务账号、密钥、天气详情令牌和网络代理均从正式配置页读取，不再打包 `.env.prod` 或硬编码凭据。
5. 定时任务：签到高级页与全局任务中心；新闻/天气任务复用“常用指令”的正式内容服务配置。

商业载荷诊断必须同时通过功能目录、Schema JSON 和高级页静态资源检查。配置声明存在但资源缺失时，安装诊断直接失败，不能把空功能展示给客户。

## 客户可见信息架构

1. 运行中心：中央一键启动、启动服务/打开微信/登录完成三步进度、微信/机器人/消息服务状态、最近运行。
2. 机器人设置：名称、简称、对外称呼、欢迎语、管理员 wxid、微信路径与数据维护。
3. 回复模型：DeepSeek 预设与 OpenAI 兼容接口、API 地址、模型名、密钥遮罩。
4. 功能中心：仅列出实际交付并通过发行准入的功能；自有配置中心支持动态表单、独立模型选择、功能专属高级页、启停和立即应用设置。
5. 运行日志：按客户术语区分回复引擎、微信连接、运行核心和消息转发，显示时清理底层框架名与敏感字段。

## 视觉基准

以用户 2026-09-02 提供的“姜小妹机器人商业版”参考图为准：白色品牌顶栏、深蓝侧栏、蓝色当前导航、中央双环电源启动器、右侧状态面板、底部最近运行。运行页面低密度，配置页面使用同一蓝白配色和稳定表单网格。

默认窗口使用无边框自绘标题栏；在当前 Windows 125% 缩放基准下，逻辑尺寸 1254×802 映射到参考图 1568×1003，56px 顶栏映射为 70px，212px 侧栏映射为 265px。导航必须使用线性图标，不得以数字编号代替。

## 白标边界

- 日常界面、操作提示、启动错误、诊断键名和日志来源标签不显示底层框架品牌或接入层工程名。
- 底层控制接口仅监听 `127.0.0.1`，使用随机本机凭据供自有配置中心调用；原始管理首页由中性本地服务页替代，客户只使用本项目控制台。
- 内部目录、依赖调用和兼容代码可以保留实现名称，不对客户界面开放。
- 法律声明、第三方许可证、NOTICE、SBOM 和对应源码义务不得因白标而删除；它们作为发行合规材料单独交付。

## 验收标准

- 双击入口后无需命令行即可进入运行中心。
- 点击“一键启动”会按顺序启动服务并拉起微信；重复点击不会启动第二套进程。
- 未登录、启动中、待登录、在线和失败均有文字状态，颜色不是唯一提示。
- 微信路径、机器人资料、回复模型、功能启停可从控制台保存。
- 机器人在线时，功能配置保存会调用正式配置接口并立即生效；每项已启用功能同时提供独立“重新载入设置”按钮。离线保存写入正式配置文件并明确提示下次启动生效。
- API Key 默认遮罩且不进入诊断；日志显示会清理常见密钥字段。
- 客户可见扫描不出现底层框架品牌；发行包继续拒绝旧 `Py/main.py`、Nove 文件和微信安装包。
- 开发验收不得控制用户电脑、不得代替用户打开图形界面；自动化只允许静态检查、无界面自检和不启动服务的安装模拟，最终视觉确认由用户自行打开完成。
