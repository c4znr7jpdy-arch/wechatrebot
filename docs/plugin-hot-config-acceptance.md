# 功能配置体验与热更新验收

## 交付范围

当前 `release/feature-set.json` 包含 24 个运行模块，其中 23 项在功能中心可见；新安装默认启用 10 个运行模块，其中 9 项对用户可见。群聊兼容作为默认启用的底层模块完全隐藏，不参与搜索和用户可见数量统计。全部可见功能均应提供用途、操作指引与前置条件。常用项经过按实际 Schema 路径筛选，完整可编辑参数保留在专业设置中。切换分类保留输入；未保存离开需要确认；密钥默认遮挡、留空保留，清除意图跨分类保留。不会自动绑定账号、开通外部服务或改变已有启用范围。

## 生效契约

在线保存先解析实际注册名称，不把目录名误当运行名称；旧运行版本缺少确认协议时，在写入前拒绝操作。管理器与运行端分别串行化保存，运行端在锁内核验旧版本摘要。保存随后定向重载，验证新实例、配置内容与必要的异步初始化；管理器再次回读配置摘要和启用状态。

只有上述确认通过才返回 `applied`。失败恢复原配置并重新加载；写回失败、恢复失败或请求超时明确提示，不能宣称成功。停用返回 `pending_enable`；未连接时保存为 `pending_start`（不推断进程已停止，若仍在运行，连接恢复后需重新保存确认）；向量记忆缺少数据库或向量模型时返回 `pending_setup`。这些状态均不等于功能可正常使用。正在执行的工作可能被重载中断；新配置针对后续请求，不承诺追溯修改已开始的工作。

## 专属配置页核对

| 功能 | 实际更新路径 | 本次处理 |
|---|---|---|
| 长期记忆 | 原配置对象 + 缓存刷新钩子 | 缓存刷新或持久化失败时恢复旧设置，移除错误回包里的原始异常 |
| 语音克隆 | 当前运行配置、声音路由、客户端签名、原生配置 | 原生配置优先于旧本地副本；队列繁忙时拒绝无法即时应用的队列设置；写入失败保留原设置 |
| 图片生成 | 模型管理器先持久化，后替换当前配置 | 保留现有即时配置路径，测试失败时缓存不更新 |
| 定时任务 | 账号管理器；任务保存后同步当前调度器 | 任务注册失败向上传递；写操作按当前会话和可靠管理员身份隔离，共享账号签到仅限机器人管理员 |
| 短剧 | 无缓存任务存储 + 重新注册当前计划 | 清理原计划失败则停止应用新计划，避免重复推送 |
| 表情管理 | 规则/表情包存储 + 当前人格缓存刷新 | 验证规则保存先刷新当前人格再返回成功 |

群聊分析等待延迟初始化并检查结果；其内部定时分析任务被跟踪，在重载时取消旧任务，避免旧实例重新启动推送；分析数据改读新桥接持续记录的本机消息库，并按机器人账号与精确群标识隔离，旧库未归属消息不会被新账号继承。记忆管理等待初始化结果，并区分缺少服务和实际配置失败。
