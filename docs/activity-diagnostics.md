# 运行记录与问题报告

目标版本：0.9.9。更新类型：管理器增量；不修改运行时、依赖或原生 hook。

## 用户操作

运行记录默认显示错误与警告。可按来源、时间、关键词筛选，展开技术详情，复制单条或首个符合筛选条件的问题。复制报告包含版本、构建、事件编号、发生时间、错误码、来源、操作、具体异常和可获取的堆栈、附近日志。复制失败时可展开报告手动选择复制。

导出诊断文件复用现有维护服务，在安装目录 `logs/` 保存 JSON。此入口附带最近日志片段，不受页面筛选限制；设置页面原有诊断导出仍只包含安全摘要。导出超时只表示未收到确认，后台可能仍在保存。

发送耗时位于折叠的“诊断工具”，只有用户主动点击才发送测试。接口接受请求显示“已提交微信接口”；结果未知要求先核对聊天记录，不能自动重复发送。

## 数据与兼容

- `get_activity` 继续返回数组，保留既有 time/event/title/status/code 字段，增加 id、level、来源、message、detail、context、count、report 等字段。
- 复用生命周期事件、回复引擎、微信连接、运行核心、消息转发与更新日志。只显示最近 48 小时；每个文件最多读取最近 256 KiB / 1200 行，返回最多 300 条异常、100 条普通记录；不扫描完整载荷。
- 保留异常后的多行堆栈。相同来源、操作、错误码、级别和内容连续发生且间隔不超过五分钟时合并计数；安静超过五分钟后再次发生会建立新记录。无日期日志按文件修改时间判断保留范围，但不把该时间伪造成事件发生时间。
- 新生命周期事件带 UUID；旧事件和运行日志使用派生编号。旧记录缺少堆栈、操作或状态时明确标记未提供，不推断已恢复。
- 生命周期日志在写入和读取时自动清理超过 48 小时的记录，当前文件和轮转文件都适用。管理器重复异常按短窗口原子更新同一条记录，保留事件编号、首末时间和次数，逐秒计数保证跨保留边界时只保留窗口内的次数；重启后继续聚合。日志到达 2 MiB 后保留一份轮转文件。引擎和桥接正在追加的日志仅过滤读取结果，不原地重写外部进程的日志。
- 页面脚本异常和未处理异步异常进入有界内存队列，通过 `record_ui_error` 脱敏落盘；不把原始错误写入浏览器持久存储。前端按签名去重，服务端每分钟最多接收 20 条。保存失败显示明确提示，不递归记录自身失败。
- 普通设置接口的返回错误结构保持兼容，新增事件编号与记录状态。采集日志失败不能覆盖原始操作错误。
- 未连接或连接过程中无法确认账号属于预期未就绪状态：历史、旧定时任务和统一定时任务接口继续返回 `11007`，保留页面已有数据并禁止不确定身份的数据访问，但不重复写入运行警告。

## 错误目录与接入边界

`src/wechatrebot_manager/error-codes.zh-CN.json` 是五位数字错误码的权威目录，包含本次定义的环境、连接、核心、配置、模型、发送、任务及页面错误。更新继续复用 `UPD-*`，授权继续复用 `LIC-*`。

本次已接入管理器异常、页面异常、配置冲突与读取、诊断导出、备份恢复、数据库异常、模型测试/发现的有类型 HTTP/网络异常、授权错误及定时测试发送的失败/待确认/跳过。日志适配器识别明确的 OpenAI SDK 异常类型；只有服务明确返回 insufficient_quota 才分类为额度不足，单独 429 只表示限流。

目录中其他细分编号预留给上游逐步补充结构化证据。本次不修改各插件和引擎的内部协议；无法可靠分类的日志展示 `19000` 与脱敏后的实际异常，而不是根据聊天中的数字或猜测生成错误码。通用定时操作异常保留原始异常，并使用 `18004`；没有保存结果证据时不宣称保存一定失败。

## 隐私与容量

显示、复制、导出经过同一脱敏边界，处理凭据字段、Authorization/Cookie、带密钥查询串的 URL、个人标识、个人路径、结构化聊天正文，以及已知引擎聊天和工具输出日志。堆栈不采集局部变量；保留模块、文件名和行号。新插件自定义日志格式仍需遵守不写入聊天正文或凭据的约定，并补充对应脱敏测试。

单条报告对超长内容明确标注截断，不能将最近日志片段描述为完整历史。报告中的版本是收集报告的管理器版本，旧错误发生时的版本未记录时不能反推。

## 验证

定向测试覆盖多行异常与上下文、敏感字段、旧事件兼容、错误级别、限流/额度区分、日志读取失败、重复合并、读取上限、导出一致性、页面错误留存、分页、筛选、空态、HTML 转义和复制失败。浏览器使用静态预览验证，不启动机器人或发送真实微信消息。
