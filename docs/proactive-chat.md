# 主动聊天的使用范围

微信群的主动聊天范围统一由「群聊&私聊管理 → 可用功能 → 主动聊天」决定，不再要求在插件里重复填写群聊对象列表，也不用为群聊获取 `/sid`。插件的群聊总开关、沉默时间、发送间隔、免打扰、未回复上限和随机插话设置继续有效。

## 设置步骤

1. 在群聊管理选择当前机器人账号和目标群，允许「主动聊天」，保存。
2. 在功能中心的「主动聊天」打开群聊总开关，设置沉默时间和触发间隔。只想冷场后发言时，关闭「群聊随机插话」。
3. 群里有新消息后开始计算沉默时间。沉默时间结束后才按触发间隔安排发送，不保证满沉默时间立即发出。
4. 如需在机器人启动后、群里一直无人发言时也创建任务，另行打开插件的「自动主动消息功能」。它默认关闭，升级不会自动开启。

私聊仍需明确填写对象列表，避免把默认允许的私聊功能范围扩大为主动联系所有好友。非微信平台保留原插件的对象列表行为。群聊管理中的定时任务开关、安静时段和每日任务上限只管理定时任务；主动聊天使用插件自己的免打扰和未回复上限。

## 配置兼容与权限

- 原有插件名单保存在配置中，以兼容私聊和非微信平台；微信群不再以旧名单为授权依据，也不会把旧名单自动迁移为群权限。
- 群聊管理没有允许主动聊天的群，即使留在旧插件名单中，也不能主动生成或发送消息。
- 运行时启动发现已授权群时，按实际登录的机器人账号读取群设置；无法确认账号或读取权限时不建立新授权。
- 已建立的任务在生成和发送前重新校验账号与群权限。取消群权限后，旧任务不能继续发送。
- 管理器仅在已安装插件声明支持统一群权限后隐藏重复群聊名单。旧插件运行时仍显示该设置，需要同步更新插件才能使用新行为。

这项改动需要管理器与插件源码一同更新；不修改 Python 依赖或 AstrBot 核心补丁。仅更新管理器不能改变旧插件的名单检查。
