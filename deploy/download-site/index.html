安装指南

三步完成安装

安装包已经包含机器人运行所需组件，不包含微信客户端本身。

下载 ZIP

点击上方按钮，将最新 Windows 完整安装包保存到本机。

完整解压

在 ZIP 上选择“全部解压”，确保 EXE 与 payload.wrb 位于同一文件夹。

启动安装

双击 WeChatReBot.exe，按界面引导选择微信环境并完成安装。

不要直接在压缩包内运行，也不要只复制 WeChatReBot.exe。 缺少同目录载荷文件会导致安装失败。
