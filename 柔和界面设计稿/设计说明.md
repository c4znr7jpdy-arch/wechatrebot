# 柔和界面设计说明

本设计稿把管理器内置界面改成"柔和浅色"方向：冷调近白表面、大圆角、分层柔和投影、玻璃质感顶栏、粉彩状态色与胶囊控件。改造范围是**视觉层**，不改信息架构、交互流程、文案术语、数据来源与安全边界。

- 基准视觉：`DESIGN.md`、`UX-CONTRACT.md`、`release/premium-ui.json`
- 改造对象：管理器内置 Web UI（`src/wechatrebot_manager/app_webui/`），由 Edge WebView2 承载
- 覆盖范围：9 个页面（运行中心、功能中心、群聊与私聊配置、消息中心、定时任务、运行记录、订阅与授权、帮助、机器人总设置）及弹窗、提示、日期弹窗

## 相对改造前的变化

| 维度 | 改造前 | 改造后 |
|---|---|---|
| 画布 | 暖灰 `#f3f2ee` | 冷调近白 `#f4f5f7` |
| 侧栏 | 暖灰 `#eae9e3`，选中项为深色实心块 | 纯白表面 + 发丝分隔线，选中项为柔和蓝胶囊 `#eaf1ff` / `#1f56d9` |
| 面板圆角 | 8px | 20px（内层卡片 18px，控件 12px，胶囊 999px） |
| 投影 | **无**（`--shadow: none`） | 三级柔和投影，最浅 `0 6px 20px rgba(16,24,40,.06)` |
| 顶栏 | 不透明白底 | 半透明 + `backdrop-filter`，内容滚动到底下仍可读 |
| 按钮 | 圆角矩形 10px | 胶囊；主按钮带柔和彩色投影 |
| 状态 | 描边小标 | 粉彩胶囊 + 圆点 + 文字，避免只靠颜色 |
| 标题字 | Alimama 数黑粗体 | 改用已内置的阿里巴巴普惠体 2.0 粗体，字重更轻、更接近参考图 |

主色沿用 `DESIGN.md` 的 `#2f6bff`。风格变化由表面、圆角、投影、字重承载，不推翻既有品牌色。

## 启用与关闭

皮肤是附加层，**默认不生效**，出厂外观在未启用时保持字节级不变。

| 操作 | 效果 |
|---|---|
| `?style=soft` | 本次启用柔和皮肤，并记住选择 |
| `?style=default` | 恢复出厂外观，并清除记忆 |

记忆存在浏览器配置的 `localStorage` 键 `wxrebot-skin`。首帧前由 `soft-theme.js` 写入 `html[data-skin="soft"]`，因此不会出现"先按旧样式画一帧再变"的闪烁。

## 严格遵守的约束

- **原生控件不动**：`release/premium-ui.json` 声明 Date 与 Select/Listbox 归原生所有。皮肤只调整这些控件的外框（描边、圆角、内边距、底色），不重做弹层、箭头或键盘行为。
- **无新增引擎依赖**：只用仓库既有基线已使用的特性（`backdrop-filter` 见 `design-overrides.css`）。刻意不使用 `color-mix()`，颜色混合一律写成显式 `rgba` 与每组强调色的描边令牌。
- **无新增字体**：仅使用已内置的阿里巴巴普惠体 2.0 与 Alimama 数黑。
- **最小窗口 1080×680** 与 900px 压力宽度：窄屏实测无横向溢出。
- **可达性**：焦点环保持可见（2px 主色描边 + 3px 柔和外环）；状态同时用颜色、圆点与文字表达；`prefers-reduced-motion` 下移除过渡与位移动效。
- **不改契约**：生命周期状态、术语（机器人 / 微信连接 / 功能 / 消息中心 / 运行记录）、流程账本、确认层与危险操作的二次确认全部沿用。

## 文件

| 文件 | 作用 |
|---|---|
| `src/wechatrebot_manager/app_webui/soft-theme.css` | 皮肤本体（由分片拼装生成，勿直接编辑） |
| `src/wechatrebot_manager/app_webui/soft-theme.js` | 启用开关，从 `?style=soft` 设置 `data-skin` |
| `src/wechatrebot_manager/app_webui/index.html` | 引用上述两个文件（`<head>` 末尾，皮肤样式排在最后以压过既有层） |
| `src/wechatrebot_manager/plugin_center_web.py` | 管理器资源白名单新增两条，否则 `/soft-theme.*` 会 404 |
| `layers/` | 皮肤分层源文件：令牌与外壳、运行中心、功能中心、群聊与消息中心、定时任务与运行记录、设置与订阅与帮助 |
| `build_skin.py` | 把 `layers/*.css` 按文件名顺序拼装为 `soft-theme.css` |
| `screens/` | 设计稿 PNG，共 25 张 |
| `设计稿总览.html` | 按类别浏览全部设计稿 |
| `导出设计稿.ps1` | 一键重新渲染设计稿 |
| `capture_soft_skin.py` | `导出设计稿.ps1` 调用的取景驱动 |

修改皮肤请编辑 `layers/` 中的分片，再运行下面的命令重新生成；直接改生成文件会在下次拼装时被覆盖。

```
python 柔和界面设计稿/build_skin.py
```

## 复现

```
.\柔和界面设计稿\导出设计稿.ps1
```

脚本用内置的 `?preview` 夹具渲染真实界面，**不启动机器人、不读写安装目录、不构建安装包**。需要 Python 3.13 与 `playwright` 包（含 chromium）。`-Before` 参数改为渲染出厂外观，用于对照。
